# REVENIR — Link da bio

Página responsiva de links da **REVENIR Estética Avançada**, pronta para hospedagem gratuita via GitHub Pages.

## Publicar no GitHub Pages

1. Faça login no GitHub (ou crie uma conta em https://github.com).
2. Crie um repositório público com nome `revenir-links` (ou outro de sua preferência).
3. Envie `index.html` e a pasta `assets` para a raiz do repositório, mantendo a estrutura original.
4. No repositório, acesse **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main`, a pasta `/ (root)` e salve.
6. Aguarde a publicação indicada pelo GitHub. O endereço normalmente segue o formato `https://SEU-USUARIO.github.io/revenir-links/`.
7. Adicione esse endereço ao campo de links da bio do Instagram.

A página incorpora uma extração visual da logomarca a partir da arte de referência enviada pelo cliente. Para aprimorar posteriormente a nitidez em todos os dispositivos, basta substituir `assets/logo-revenir.png` pelo arquivo oficial de marca mantendo o mesmo nome.
